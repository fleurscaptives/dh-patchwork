# DH Patchwork

A collection of small-scale **Digital Humanities projects, experiments, and academic assignments** exploring the intersection of humanities research and digital technologies.

This repository brings together practical work developed during my academic studies, covering different aspects of digital scholarship: web design and development, handwritten text recognition (HTR), and digital publishing.

## Projects

### 1. Web Design and Development
```text
uzumaki-web
```
A static website developed as part of a university course in Web Design and Development. The project revolves around the manga *Uzumaki* by illustrator Junji Ito, encouraging reading and further exploration of the story. 

The project explores front-end web technologies and JavaScript-based interactivity, focusing on website structure, user interaction, and interface design.

**Technologies:** HTML, CSS, JavaScript.

### 2. HTR on Occitan Songbooks
```text
provençal-htr
```
A project exploring Handwritten Text Recognition applied to medieval Occitan songbooks (*chansonniers*).

The work involved experimenting with HTR workflows for the transcription of medieval manuscript witnesses, including the training and fine-tuning of a custom HTR model using Transkribus. Model performance was evaluated and improved through iterative fine-tuning, with particular attention to Word Error Rate (WER) and Character Error Rate (CER).

The project explored the challenges of applying automated text recognition to medieval manuscripts, particularly in relation to palaeographical variability and historical handwriting.

**Tools and methods**: Transkribus, HTR model training, fine-tuning, WER and CER evaluation.

### 3. Digital Publishing
```text
frog-princess-ed
```
An interactive digital edition of the Russian folktale The Frog Princess (Tsarevna-Lyagushka), developed as part of a university assignment.

Created using Adobe Illustrator, the project explores interactive digital storytelling and editorial design, combining visual elements and interactive features to enhance the reading experience.

**Tools:** Adobe Illustrator.
